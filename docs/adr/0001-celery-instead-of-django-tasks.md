# ADR-0001: Celery для фоновых задач, а не django.tasks

Статус: принято. Дата: 2026-11-05.

## Контекст
Нужны периодические задачи (раз в минуту, 5 минут, сутки), повторы при сбоях внешних систем, `acks_late`, лимиты времени. В Django 6.0 появился встроенный `django.tasks`.

## Варианты
- A. `django.tasks`.
- B. Celery 5.6 + beat, брокер Redis.

## Решение
B.

## Почему
Встроенные бэкенды `django.tasks` годятся для разработки и тестов, расписания у них нет. Celery уже пройден в курсе и умеет всё нужное из P-8.

## Цена
Два дополнительных процесса (worker, beat) и Redis как брокер. Если брокер недоступен, фоновые задачи стоят. Поэтому события между модулями пишутся в outbox в БД и досылаются после восстановления (будет отдельный ADR).
