# Релиз v0.0.0 (КТ-0): каркас

## Что вошло
- Django 6.1 + DRF, настройки `base` / `dev` / `test` / `prod`, pytest.
- Docker Compose: web (gunicorn), worker, beat, db (PostgreSQL 17), redis, mailpit.
- Логи с `request_id`, заголовок `X-Request-ID`.
- `/health/live/` и `/health/ready/` (БД и Redis).
- Swagger UI `/api/v1/docs/`, схема `openapi.yaml`.
- `scripts/check_all.sh`, `check_layers.sh`, `check_history.sh`.
- `AGENTS.md`, `docs/architecture.md`, ADR 0001–0004.

## Сценарий демо (10 минут)
1. `docker compose up -d --build`, затем `docker compose ps`: все сервисы запущены.
2. `curl localhost:8000/health/ready/` отвечает `{"status": "ok", "checks": {"db": "ok", "redis": "ok"}}`.
3. `docker compose stop redis`, затем снова `ready`: 503, `redis: fail`, а `live` по-прежнему 200.
4. `bash scripts/check_all.sh` завершается «ЗЕЛЁНЫЙ».
5. Добавить в `apps/catalog/` файл с запрещённым импортом: `check_layers.sh` падает.
